# imersao-dados-alura
# 📊 Dashboard de Salários na Área de Dados

Este projeto consiste em um dashboard interativo desenvolvido em Streamlit para análise de salários na área de dados, utilizando dados trabalhados durante a Imersão em Ciência de Dados com Python da Alura.

O dashboard permite explorar informações salariais por ano, senioridade, tipo de contrato, tamanho da empresa, cargo, tipo de trabalho (remoto/presencial) e país, oferecendo uma visão clara e dinâmica do mercado de dados.

---

## 🚀 Objetivo do Projeto

- Aplicar conceitos de análise exploratória de dados (EDA)
- Desenvolver um dashboard interativo com Python
- Facilitar a análise do mercado de trabalho em dados
- Consolidar os aprendizados da Imersão da Alura
- Criar um projeto prático para portfólio profissional

---

## 🧠 Análises Disponíveis no Dashboard

O dashboard permite:

- Visualizar métricas gerais (salário médio, máximo, total de registros)
- Identificar o cargo mais frequente
- Analisar os Top 10 cargos por salário médio
- Explorar a distribuição salarial por senioridade
- Ver a proporção entre trabalho remoto, híbrido e presencial
- Comparar o salário médio de Cientistas de Dados por país
- Filtrar dinamicamente os dados por múltiplos critérios

---
